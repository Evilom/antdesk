# AntDesk 个人 PM 助手

2026-09-14 本机实现。入口集中在宠物和现有助理面板，不需要另开语音、目录或记忆管理网页。

## 首次使用

1. 打开本机构建的 AntDesk；如果此前的测试实例仍运行，先从 AntDesk 菜单退出，再重新启动。
2. 设置 → 个人 PM 助手 → **自动连接本机语音**。它读取已有的 `chatgpt-web-voice/.env`，向本机网关申请专用设备身份，Mac 上存入系统钥匙串。已有有效身份会复用，不返回管理凭据或设备密钥到界面。
3. 在同一设置里添加允许读取的具体目录。初始列表为空；不会默认开放整个磁盘。选中的文本片段会在相关提问时发送给当前配置的语音或文字服务。
4. 回到宠物，点麦克风即可持续通话；旁边可静音、打断回复和挂断。收起或关闭主面板会隐藏它，保留连接；退出应用会停止通话。

首次仍需要系统麦克风授权。网关不在默认项目位置时，可通过 `ANTDESK_VOICE_CONFIG_FILE` 指定现有集中配置文件，或展开手动连接。语音声音和主动汇报仍在同一设置内。

## 记忆如何保留

- 对话记录由 Rust 写入应用数据目录的 `assistant/pm.sqlite3`。Mac 默认位置为 `~/Library/Application Support/com.antdesk.app/assistant/pm.sqlite3`。
- 对话字幕和文字回复按消息身份保存版本；新对话、断线和重新启动不清空原记录。界面仅保留有限消息以控制长时间运行的内存和渲染负担。
- 说或输入“记住：……”可保存长期记忆；也能在设置里明确保存。界面只有收到存储成功结果才显示保存成功。
- 每次语音连接与重连都重新加载长期记忆、近期历史、日程和宠物状态。提问时按关键词及中文相邻字检索历史和已授权目录，不把整个磁盘或全部历史塞入会话。
- 历史回答仅作为引用，不代表已经执行或当前仍然正确。长期记忆带来源和时间；语音会话与记忆存储相互独立。
- 现有 Hermes 知识库仍通过原有本机接口读取；本功能不删除或重置 Hermes、Codex 的知识和索引。

备份运行中的 SQLite 应使用 SQLite backup API，避免仅复制主文件而漏掉 WAL。此版本没有删除记忆或重置索引的入口。

## 工作状态与目录范围

- 助理面板的“工作状态”每 15 秒读取 Codex 最新 12 个未归档任务的本机索引和有限事件尾部，展示最近一轮状态、进展原文片段和更新时间。
- 本机没有可连接的 Codex 控制 socket，因此使用只读记录。`最近有活动`不等于确认仍在运行；过期运行记录会标为未知。一轮完成不代表整个项目完成。
- 开启“通话中主动汇报”后，会同步日程，并在观察到已有 Codex 任务最近一轮完成或中断时简短提醒。
- 宠物每 5 秒发布实际动画、行为模式、锁定状态、睡眠阶段、情绪数值和任务统计。上下文包含采样时间，旧快照不能当作当前事实。
- 目录查询只读取已连接目录下有限深度、有限数量、每个不超过 64 KiB 的常见文本文件；跳过隐藏配置、依赖、构建产物和常见密钥文件。符号链接不得越出授权目录。它是有限片段检索，不是对整棵目录的完整审计。
- 本版只读文件和工作记录，不会替用户执行命令、修改项目或发布消息。

## 常驻与限制

Mac 语音主窗口关闭了后台节流（该系统能力要求 macOS 14 或更新版本）。可恢复的网络错误会按最多 30 秒间隔持续重试；静音状态在重连后保持。用户挂断、鉴权失败、麦克风拒绝和上游明确要求挂断时停止，不无限重试额度错误。

电脑睡眠、断网或上游账号限制仍会中断通话，不能保证全天无缝不断线。当前沿用网页语音协议，通过后续消息补充检索资料；并非原生同步工具调用，语音可能先回应再根据资料补充。跨会话检索是本机持久化与有限上下文恢复，不保证逐字回忆所有旧对话。浏览器预览没有本机持久化能力，实际使用应打开桌面应用。
