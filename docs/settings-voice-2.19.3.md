# v2.19.3 设置与语音切换修复

设置首页改为语音与助理、项目与记忆、提醒与简报、外观与桌宠、连接与应用五个入口。地址与密钥默认折叠，开关即时保存，连接字段分别保存。通话期间禁用语音服务地址和密钥的修改，声音选择在下次通话生效。

语音切换先停止本机采音、解绑数据及音频回调，再等待已发出的创建请求完成及旧服务会话释放。释放失败保留旧会话标识，下一次连接先重试释放；不会删除未知或其他设备的会话。旧连接的失败回调不能重新启动已停止的客户端。新对话保留静音状态并自动接回语音，历史记录及长期记忆保留。
